# Sivon

Two music discs and one block sound, all from the same theme.

---

## English

### What it adds

- **Two music discs**
  - **Rain Love (Sivon Edition)** — artist: Gudaofei, Rainie Yang
  - **Ice Love**
  - Play them in a jukebox like any vanilla disc. Both appear in the mod's own creative tab.
- **Ice block sounds**: ice, packed ice, blue ice and frosted ice now play the Sivon ice sound for breaking, placing, stepping, hitting and falling.

### Ice sound toggle

The ice sound replacement can be turned off:

- Install **Cloth Config** → open the config screen (**Mod Menu** on Fabric, or the mod list on NeoForge) → **KeenLib → Sivon → Replace ice block sounds**.
- The setting is stored in `config/sivon.json` and applies immediately; no restart needed.

### Requirements

- **KeenLib** is required and must be installed separately.
- **DiscAPI** is already bundled inside this jar, so do not install it again.

### Installation

1. Install a Minecraft instance with Fabric or NeoForge.
2. Put the jar for your loader and the KeenLib jar into the instance `mods` folder.
3. Optionally add Cloth Config to get the settings screen.

## 中文

### 新增内容

- **两张唱片**
  - **雨爱（司凤版）** —— 作者：古岛斐 杨丞琳
  - **冰爱**
  - 和原版唱片一样放进唱片机就能播放，两张都在本模组的创造模式标签页里。
- **冰块音效**：冰、浮冰、蓝冰、霜冰的破坏、放置、踩踏、敲击与落地音效都换成司凤的冰冰冰。

### 冰块音效开关

冰块音效替换可以关掉：

- 安装 **Cloth Config** → 打开配置界面（Fabric 走 **Mod Menu**，NeoForge 走模组列表）→ **KeenLib → 司凤 → 替换冰块音效**。
- 设置保存在 `config/sivon.json`，改完立即生效，不用重启。

### 前置

- 必须另外安装 **KeenLib**。
- **DiscAPI** 已内置在本 jar 内，不要重复安装。

### 安装

1. 安装对应加载器（Fabric 或 NeoForge）的 Minecraft 实例。
2. 把对应加载器端的 jar 与 KeenLib 的 jar 放进实例 `mods` 目录。
3. 可选：再装 Cloth Config 以获得设置界面。
